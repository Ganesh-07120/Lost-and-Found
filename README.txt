LOST & FOUND MANAGEMENT SYSTEM
Created by Ganesh Dubey

HOW TO RUN
1. Extract the ZIP file.
2. Open the LostFound_Complete folder in Visual Studio Code.
3. Install the VS Code extension called Live Server (recommended).
4. Right-click index.html and select Open with Live Server.
5. For the admin features, open login.html and sign in with the demo admin account below.

FEATURES
- Retro-inspired responsive layout for desktop and mobile
- Dark mode / light mode toggle; selected theme is remembered in this browser
- Report Lost and Report Found forms with image preview
- Item list with search and Lost/Found filter
- Reports saved in browser localStorage and restored after refresh
- Claim Item workflow with a verification-detail prompt
- Admin can review claims and approve or reject them
- Approving a claim marks the report resolved and creates notifications
- In-app notifications, unread badge and mark-as-read action
- Admin can mark reports resolved or delete reports
- User dashboard showing the user's own reports
- Student registration with full name, student/roll number, email, course/year, department/college and optional contact number
- Duplicate email and student/roll number checks within this browser
- User dashboard welcomes registered students by their full name
- Profile username editing

IMPORTANT LIMITATIONS
This is a beginner-friendly frontend college demo. It stores data in the current browser's localStorage, not in an online database. Different users on different devices do not share data. Clearing browser/site data can delete reports and notifications. Registration details and demo passwords are stored locally in plain text and are NOT secure. Do not use real personal or sensitive information. The registration form is for a college demonstration only; it does not verify student identity or send emails. Real deployment requires a secure backend, database, authentication and authorization.

IMAGE LIMIT
To reduce browser storage problems, each uploaded image must be 500 KB or smaller.
